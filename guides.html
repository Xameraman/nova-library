Start here

NOVA is a community Discord and guide network for verified Minecraft Bedrock content: direct downloads, proper credit to creators, 22 clean categories and zero ad links. Content comes mainly from CurseForge and MCPEDL and is re-hosted or linked through trusted mirrors. NOVA is completely free — no paywalls and no ad gates.

Quick start in six steps

  1. Join the Discord. discord.gg/Zc5pPEZYpe
  2. Read the rules. English only, moderated by the Wick bot.
  3. Get the Key Access role to unlock the main channels.
  4. Browse a category in Discord, or use the search and filters on this website.
  5. Click a direct download link. Links come from CurseForge, MCPEDL, MediaFire, MEGA, Google Drive or Proton Drive — no ad pages.
  6. Install it. Follow Download & install, and the matching host guide if the link goes through a file host.
Bedrock and Java are different games files. Bedrock content (.mcpack, .mcaddon, .mcworld, .mcskin) will not work on Java Edition, and Java files (.jar mods) will not work on Bedrock. Check which edition you play before you download.

Find something to download

On this website

  1. Type a name in Search Nova Library. On a computer, Ctrl/⌘ + K jumps to the search box.
  2. Narrow the list with a Category and, if you like, a Secondary Tag.
  3. Change the order with the sort menu: Newest, Oldest, A–Z, Recently Viewed, Most Viewed or Favorites.
  4. Not sure what you want? Press Surprise Me for a random pick.
  5. Switch between the grid and the image layout with the two layout buttons (on a computer: G and I; R is Surprise Me).
  6. Open an item to see its details and download link.

The Preferences menu also has an Infinite Scroll switch and shortcuts to these guides, Partnerships and Statistics.

On Discord

  1. Pick a category channel. If you cannot see all 22, open the top of the channel list → Channels & Roles → Roles tab and choose individual category roles, or take Access all Without Pings. Channels appear instantly.
  2. Click the direct download link in the post.
  3. Missing something? Use Request it on Discord at the top of the Library.

NOVA Assistant can help with Minecraft add-ons, texture packs, skins, worlds, setup and troubleshooting. To find packs, use the search on this website or the Discord search channels; you can ask naturally (for example “find me the furniture pack”), and Find:, Search: and Look up: also work. If it does not answer, wait a few seconds and retry, or ask in a support channel.

About view counts. The number on each item counts unique browser views: each browser profile counts once per item. Clearing site data, using a private window, or using another browser or device looks like a new viewer. It is a count of browsers, not of people, and it is tracked within NOVA only — not linked to MCPEDL, CurseForge or other platforms.

Download & install

First work out what kind of file you have, then follow the steps for your edition.

What is this file?

File types and what to do with them
FileEditionWhat to do
.mcpackBedrockTap it, open with Minecraft, then activate the pack in your world settings.
.mcaddonBedrockTap it, open with Minecraft, then activate both the behaviour and the resource pack.
.mcworld, .mcskinBedrockTap the file and open it with Minecraft to import it.
.zip (Bedrock content)BedrockRename it to .mcpack or .mcaddon, then import as above.
.jarJavaA mod. Put it in .minecraft/mods and launch with the matching Forge or Fabric profile.
.zip (Java content)JavaResource pack → resourcepacks folder (do not extract). Data pack → saves/<world>/datapacks. World → extract into saves.
.exe, .apk, .msiNeitherNever open these. They are not Minecraft content formats. Delete the file and report it in the NOVA Discord.

Bedrock Edition

  1. Check the extension: .mcpack, .mcaddon, .mcworld or .mcskin. Never open .exe, .apk or .msi.
  2. Download from a trusted source: MCPEDL, CurseForge or the NOVA Discord.
  3. Open a file manager (ZArchiver on Android) → Downloads → tap the file.
  4. If it is a .zip, rename it to .mcpack or .mcaddon.
  5. Choose Open with Minecraft and wait for “Successfully Imported”.
  6. In your world: Resource Packs / Behaviour Packs → move the pack to Active. For a .mcaddon, activate both the resource and the behaviour pack.
  7. Turn on Experimental Gameplay if the pack needs it (World Settings → Experiments).

Java Edition

  1. Install a mod loader that matches your Minecraft version: Forge (files.minecraftforge.net) or Fabric (fabricmc.net). Download the installer, run it and pick your Minecraft version.
  2. Open your .minecraft folder (see the box below).
  3. Create a lowercase mods folder if it is missing, then put the .jar inside. Do not double-click it.
  4. Launch with the matching loader profile; the mod appears in the Mods menu.
  5. Resource packs: Options → Resource Packs → Open Pack Folder and drop the .zip in (do not extract it).
  6. Data packs: put the .zip in saves/<world>/datapacks, then run /reload.
  7. Worlds: extract the .zip and move the folder into .minecraft/saves.

Where is .minecraft?

  • Windows: press Win + R, type %appdata%\.minecraft
  • macOS: Cmd + Shift + G, then ~/Library/Application Support/minecraft
  • Linux: ~/.minecraft

*Console players cannot import files directly: download on a phone or PC first, then sync through your Microsoft account.

Example: installing a Bedrock add-on

  1. You download a file called example.mcaddon from a NOVA link.
  2. Tap it in your file manager and choose Open with Minecraft. You see “Import Started” and then “Successfully Imported”.
  3. Create or edit a world. Under Resource Packs and again under Behaviour Packs, move the add-on to Active.
  4. If the add-on page says it needs it, switch on Experimental Gameplay in World Settings → Experiments, then play.

Where content is published

Marketplaces that host mods, add-ons and packs.

🔥
CurseForge
Java & Bedrock — pick your edition
›

CurseForge is the largest Minecraft modding platform. It hosts mods, modpacks, resource packs, shaders, data packs and worlds for both Java and Bedrock.

Quick start

Java: search the mod → check version and loader → download the .jar → put it in .minecraft/mods. Bedrock: browse the Bedrock section → download .mcpack/.mcaddon → tap the file → activate it in world settings.

Step by step

  1. Java: go to curseforge.com/minecraft, search, and look for the Verified badge.
  2. Check compatibility: Minecraft version, mod loader (Forge or Fabric) and dependencies (Relations tab).
  3. Files tab → find the right version → ⋯ → Download File → wait out the short countdown.
  4. Put the .jar in .minecraft/mods (create the folder if missing) and launch with your loader profile.
  5. Bedrock: go to curseforge.com/minecraft-bedrock and search or browse.
  6. Confirm the file is .mcpack, .mcaddon, .mcworld or .mcskin — a .jar is Java only.
  7. Files tab → Download → wait out the countdown, then tap the file and open it with Minecraft.
  8. Activate the pack(s) in world settings (both for a .mcaddon) and enable Experimental Gameplay if needed.

If something goes wrong

  • Mod not appearing (Java): check the mods folder, the loader version and missing dependencies.
  • Game crash: remove mods one by one, check dependencies and update Java.
  • Import failed (Bedrock): rename the .zip to .mcpack and use “Open with” Minecraft.
  • Pack not working: activate both packs and enable Experimental Gameplay.
  • Countdown will not start: refresh the page and avoid clicking ads.

Stay safe

  • Only download from curseforge.com.
  • Never click banner ads — the real button is inside the Files tab.
  • Java .jar and Bedrock .mcpack files are not interchangeable.
  • Check dependencies before downloading and never double-click a .jar.
📱
MCPEDL
Bedrock add-ons, maps & textures
›

MCPEDL (mcpedl.com) is the largest free site for Bedrock content — add-ons, maps, texture packs and skins. No account needed.

Quick start

Open MCPEDL → Skip to Download (or scroll to the bottom) → pick the version link (small green text, not the big banner) → download the file → tap to import → activate in world settings.

Step by step

  1. Find your content with the search or categories on mcpedl.com.
  2. Click Skip to Download, or scroll to the bottom of the page.
  3. Pick the link that matches your Minecraft version (Settings → About).
  4. Click the real link: small green text inside the content area, never a large flashy banner.
  5. It leads to a direct file or an external host (MediaFire, Google Drive, Dropbox). If Linkvertise appears, see the Linkvertise guide below.
  6. If the file is a .zip, rename it to .mcpack or .mcaddon.
  7. Tap the file, open with Minecraft and wait for “Successfully Imported”.
  8. Activate: resource packs via Settings → Global Resources; behaviour packs via edit world → Behaviour Packs (both for a .mcaddon). Enable Experimental Gameplay if the page says so.

If something goes wrong

  • Clicked the big DOWNLOAD button and nothing happened: that was an ad. Use the small green link.
  • File downloaded as .zip: rename it to .mcpack/.mcaddon, then import.
  • Import failed: use “Open with” Minecraft and check the extension and storage permissions.
  • Add-on not appearing: activate both packs and enable the required Experimental Gameplay toggles.
  • Broken or expired link: check the MCPEDL comments or ask in the NOVA Discord.

Stay safe

  • The real link is small green text; large banners are ads.
  • .jar files on MCPEDL are Java-only and will not work on Bedrock.
  • MCPEDL often redirects to an external host — follow that host’s guide.
  • Console players: download on a phone or PC first, then sync through your Microsoft account.
🟢
Modrinth
Java mods, packs & shaders
›

Modrinth is an open-source modding platform for Java Edition only. It supports Forge, Fabric, Quilt and NeoForge, has no fake buttons and shares ad revenue with creators.

Quick start

Search the mod → check Minecraft version and loader → Versions tab → Download → put the .jar in .minecraft/mods → launch with the matching loader profile. Or use the free Modrinth App to install automatically.

Step by step

  1. Find the mod on modrinth.com.
  2. Confirm the Minecraft version, the loader (Forge, Fabric, Quilt or NeoForge) and the environment (Client or Both).
  3. Versions tab → find the matching file → Download. Mods save as .jar, packs as .zip.
  4. Open .minecraft, create a lowercase mods folder if needed and drop the .jar in. Packs go in resourcepacks or saves/<world>/datapacks.
  5. Launch with the matching loader profile; the mod shows in the Mods menu.
  6. Easiest route: install the free Modrinth App (modrinth.com/app), which manages versions and dependencies for you.

If something goes wrong

  • Mod does not work: check the loader (Fabric is not Forge), the Minecraft version and the Relations tab for dependencies.
  • Crash on launch: remove mods one at a time and make sure they all match one Minecraft version.
  • Downloaded a .zip instead of a .jar: that is correct for resource and data packs — place it accordingly.
  • Not sure which loader you have: check your launcher profile name.

Stay safe

  • Java Edition only — no Bedrock support.
  • Never double-click a .jar; place it in the mods folder.
  • Always check Relations for required dependency mods.
  • Only download from modrinth.com and avoid repacks. The Modrinth App is free — never pay an imposter.

File hosts

Cloud storage a NOVA link may point to.

📁
MediaFire
Spot the real button, avoid fake ads
›

MediaFire is a free cloud host (10 GB free) commonly used by Minecraft creators. The real download button always sits directly below the file name.

Quick start

Open the link → confirm the file name → click the large blue Download button below it → complete any captcha → save → import into Minecraft.

Step by step

  1. Open the mediafire.com link and confirm the file name and size at the top.
  2. Find the real button: a large blue Download (with the size) directly under the file name. Ignore every other button, banner or sidebar.
  3. Click it and complete a captcha if one appears.
  4. If the download does not start, allow pop-ups for mediafire.com.
  5. Import: .mcpack/.mcaddon/.mcworld → tap to import; .jar → .minecraft/mods. If it came as .zip, rename it to .mcpack/.mcaddon (not .jar).

If something goes wrong

  • Clicked an ad and a new tab opened: close it; the real button is below the file name.
  • Captcha loops: complete it carefully, clear cookies, try another browser or turn off a VPN.
  • File Not Found: the creator removed it. Ask for a new link or check the NOVA Discord.
  • Button does nothing: refresh, allow pop-ups, or try Chrome, Firefox or Brave.

Stay safe

  • The real button never opens a new tab — if it does, it was an ad.
  • MediaFire never requires installing software.
  • Brave browser helps block fake buttons automatically.
  • Always check the file extension after downloading.
☁️
MEGA
Large files, transfer quotas explained
›

MEGA is an ad-free, end-to-end encrypted cloud host. Free accounts get 20 GB of storage with a transfer quota of about 5 GB per 6 hours.

Quick start

Open the link → confirm the file name → click the red Download → wait for your browser to decrypt it → save. For folders use Download as ZIP. To skip the quota, import to your own free MEGA drive first.

Step by step

  1. Open a mega.nz/file/ or /folder/ link and confirm the file name and size.
  2. Click the red Download button. Your browser downloads encrypted data with a progress bar.
  3. It then decrypts locally (“decrypting…”); large files take longer.
  4. Save the decrypted file, then import: .mcpack/.mcaddon/.mcworld → tap; .jar → .minecraft/mods.
  5. Folders: download files one by one, or use Download as ZIP.
  6. To get around the quota: Import to Cloud Drive (needs a free MEGA account), then download from your own storage any time.

If something goes wrong

  • Transfer quota exceeded: wait, switch networks, or import to your own MEGA drive first.
  • Stuck on “Decrypting”: large files need time; after 15 minutes retry with the MEGA app.
  • Download never starts: use Chrome, Edge or Brave with pop-ups enabled for mega.nz.
  • iPhone or iPad cannot download: use the free MEGA iOS app (Safari struggles with files over about 1 MB).
  • Link not found: the sharer deleted it. Ask for a new one or check the NOVA Discord.

Stay safe

  • Never use third-party “MEGA downloader” tools — they are usually malware.
  • MEGA has no ads, so any pop-up asking for something is fake.
  • For files over 500 MB use the official desktop or mobile app.
  • Always check the file extension after downloading.
🔐
Proton Drive
Encrypted, ad-free downloads explained
›

Proton Drive is an encrypted, ad-free cloud host with no fake buttons or transfer quotas. A free account has 5 GB.

Quick start

Open the link → enter a password if asked → click Download → wait for browser decryption → save → import into Minecraft as usual.

Step by step

  1. Open the drive.proton.me link.
  2. If a password prompt appears, enter the password the creator gave you.
  3. A clean page shows the file name, size and a Download button — no ads.
  4. Click Download. Your browser decrypts the file locally (seconds to a few minutes for large files).
  5. Save the file, then import: .mcpack/.mcaddon/.mcworld → tap; .jar → mods folder.
  6. If it looks stuck, wait: decryption is a privacy feature, not a bug.

If something goes wrong

  • Download does not start: wait for decryption; if it takes over 5 minutes, refresh once.
  • Slow speed: Proton does not throttle, so check your own connection.
  • “Access Denied” or “Link Invalid”: the link may have expired. Ask the creator for a new one.
  • Password prompt but no password: contact the sharer, who set it.
  • Fails on iPhone or iPad: use Chrome for iOS or the free Proton Drive app.

Stay safe

  • There are no ads on Proton Drive — any pop-up asking for money is a scam.
  • Never install third-party “speed up” tools.
  • The decryption delay is normal; do not close the page.
  • On iOS use the Proton Drive app for files over 100 MB.

Mirrored.to
Multiple hosts — pick the safest one
›

Mirrored.to mirrors one file across many hosts. You pick the host, so your safety depends on that choice. NOVA rarely uses it and prefers direct links.

Quick start

Open the link → pick an Easy (green) host → follow that host’s steps → confirm the file extension. Avoid the red hosts.

Choosing a host

Stay safe

  • Always try an Easy host first, and use Brave for automatic ad blocking.
  • Never install anything from a host page and never allow notifications.
  • Check the file extension after every download.
  • Upfiles.com and Upload.ee carry the highest malware risk.

Link gates (ad walls)

NOVA does not use these. You may meet them on other sites.

🔗
Linkvertise
Ad wall — free tasks before the download
›

Linkvertise is a link-monetisation gateway that asks for free tasks before it unlocks a download.

NOVA does not use this link gate. It is explained only for links you meet elsewhere. If you find one inside NOVA, report it with /nova-report.

Quick start

Open in Chrome or Firefox → main button → Free Access with Ads → finish the tasks (keep tabs open, wait, captcha) → Continue → download from the final host.

Step by step

  1. Open the link in Chrome, Firefox or Edge — avoid in-app browsers (Discord, YouTube).
  2. Wait for the gateway page; a countdown may run before the main button works.
  3. Click the main button and choose Free Access with Ads. Never pay.
  4. Complete any captcha (turn a VPN off if it fails).
  5. Complete the 1–4 tasks: wait on a sponsored page (10–15 s, no clicking), watch or skip a video ad, keep an article tab open until its timer ends, a search-and-click task, follow or subscribe (look for Skip first), or open an app-store page (close it at once — no install needed).
  6. When every task shows complete, click Continue / Get Access.
  7. You land on the real file host (MediaFire, Google Drive, MEGA, …) — download there.

If something goes wrong

  • “Invalid Visit Detected”: turn off the VPN, switch network or try another browser.
  • Page loads forever: turn off ad blockers and extensions, clear the cache.
  • Continue stays grey: scroll for unfinished tasks and do not refresh (progress resets).
  • Tasks will not register: wait longer on each page and make sure you clicked the required button.
  • An install prompt appears: never install; close it and look for Skip.

Stay safe

  • Never install apps, extensions or software from task pages.
  • Only use the main button and the task elements — never banner ads.
  • Never enter payment or personal information; it is always free.
  • Do not use in-app browsers and do not refresh mid-process.
🔓
Sub2Unlock
Social tasks before the download
›

Sub2Unlock asks for social tasks (subscribe, follow, join a Discord) before it reveals a download link.

NOVA does not use this link gate. It is explained only for links you meet elsewhere. If you find one inside NOVA, report it with /nova-report.

Quick start

Open in Chrome, Brave or Firefox (not an in-app browser) → try each task’s smart skip (open it, then go back) → do the real task if that fails → wait for green checkmarks → Unlock → download from the file host.

Step by step

  1. Open the link in Chrome, Brave or Firefox — avoid the Discord, YouTube and TikTok in-app browsers.
  2. You will see 2–4 tasks. Never click banner ads, only the tasks.
  3. Smart skip first: open the task, then go straight back — it often registers as done.
  4. If that fails, do the actual task (subscribe, follow or join), then return.
  5. When every task has a green check, Unlock / Continue becomes clickable (scroll down if it is hidden).
  6. Click Unlock to reach the real file host (MediaFire, Google Drive, …).

If something goes wrong

  • Progress resets: use Chrome, Brave or Firefox; in-app browsers break sessions.
  • Tasks do not register: open the task, wait about 10 s, go back; do the real action if it still fails.
  • Unlock stays grey: scroll for hidden tasks or re-open each task to refresh it.
  • Pop-ups or new tabs: close them at once; they are ads.
  • Asked to install software or allow notifications: never do it; close the tab.

Stay safe

  • Never install apps or extensions and never allow notifications.
  • Never enter payment or personal information — it is free.
  • The FastForward browser extension can bypass these tasks automatically, or ask the sharer for a direct link.
⛓️
Urlspay
Several unlock rounds before the link
›

Urlspay is a URL shortener that forces several unlock rounds before it shows the final link.

NOVA does not use this link gate. It is explained only for links you meet elsewhere. If you find one inside NOVA, report it with /nova-report.

Quick start

Open in Chrome (not in-app) → Continue to Content → wait about 20 s → Unlock Link → scroll down → Verify → Continue. Repeat 3–5 rounds until you are sent to the file host.

Step by step

  1. Open the link in Chrome or Safari — avoid in-app browsers (Discord, YouTube, TikTok).
  2. Click Continue to Content.
  3. Wait about 20 seconds on the page without switching tabs or letting the screen sleep.
  4. Tap Unlock Link once it is active, then scroll to the very bottom.
  5. Tap Verify, then Continue when it appears.
  6. Repeat steps 3–5 for 3–5 rounds (occasionally up to 7).
  7. After the final round tap Unlock Link → scroll down → Continue / Get Link.
  8. You land on the real file host (MediaFire, Google Drive, MEGA, …).

If something goes wrong

  • Page reloads or progress resets: use Chrome or an external browser.
  • Countdown restarts: stay on the page and do not switch tabs.
  • Cannot find Verify: scroll to the very bottom, or rotate to landscape.
  • All rounds done but no link: it may need up to 7 rounds; if it still fails, ask for a direct link.
  • “Virus detected” pop-up or install prompt: it is a fake ad — close the tab.

Stay safe

  • Never pay, enter personal information or install anything.
  • Never click banner ads or pop-ups.
  • Ad blockers can break the unlock — turn one off temporarily if needed, then turn it back on.

Share content on NOVA

First decide whose work it is. A packmaker shares their own creation; a sharer passes on someone else’s, with credit.

I made it (Packmaker)

Quick way: post your MCPEDL, CurseForge or MediaFire link in the 📤 | Uploads here channel together with a preview picture.

Formal way: run /share-with-nova. It asks for:

  • name
  • file_link
  • category
  • credits
  • support_link
  • archive
  • photo

Either way a preview picture (thumbnail or screenshot) is required — submissions without one are ignored. Approved creators receive the Verified Packmaker role.

Someone else made it (Sharer)

Run /nova-share. It asks for:

  • name
  • link
  • credits
  • description
  • image
  • category
  • an optional support link

The bot posts an embed with a 🚀 Download Now button. Never present someone else’s creation as your own.

Announcing approved submissions

/nova-feature adds a permanent archive link plus up to three buttons: 🚀 Download Now, 🌌 Temp Mirror and 💝 Support the Creator. /nova-share and /nova-feature announce automatically — no extra steps.

Rules for everything you share

  • Only direct download links are accepted.
  • Always credit the original creator.
  • No NSFW, spam or paid content.
  • A preview image is mandatory; submissions without one are ignored.
  • Only submit work you made yourself, or clearly credit what it is based on, and keep descriptions accurate — do not overstate compatibility or features.
  • filego.io is never used for packmaker archives.

  • Prefer official creator pages and direct file links. A well-known host does not make a third-party file guaranteed safe.
  • Never install software, extensions or apps from a download page, and never allow notifications.
  • Never enter payment or personal information to unlock a file.
  • Brave browser blocks many ads and fake buttons automatically.
  • Bedrock files and Java files are not interchangeable.

Report a problem

Use /nova-report in the NOVA Discord for a broken link, an ad link or a link gate (such as Linkvertise) inside NOVA, or an inappropriate submission. For anything else, ask staff in the NOVA Discord.
